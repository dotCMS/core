# Phase 1 Data Model: Changing the Page of a Draft Experiment

No schema change. `page_id` is an existing column on the experiment record; this work changes only
which values may be written to it and when. Shapes below are the verified ground truth the
implementation must respect.

## Experiment (`com.dotcms.experiments.model.AbstractExperiment`)

Immutables value object; `Experiment` is the generated concrete type, built via
`Experiment.builder().from(existing)`.

| Field | Type | Notes |
|-------|------|-------|
| `id()` | `Optional<String>` | assigned on first save |
| `pageId()` | `String` (L88) | **the field this work makes patchable** |
| `status()` | `Status` (L54-57) | `@Value.Default` → `DRAFT`. Enum at L182. |
| `trafficProportion()` | `TrafficProportion` (L60-62) | `@Value.Default` |
| `goals()`, `targetingConditions()`, `scheduling()` | `Optional<...>` | untouched |

**Eligibility predicate** (FR-002), expressed against these shapes:

```
status() == Status.DRAFT
  AND trafficProportion().variants().size() == 1
  AND the single variant's id().equals(DEFAULT_VARIANT.name())
```

The size check alone is insufficient — one non-control variant would satisfy it. See research R3.

## TrafficProportion (`AbstractTrafficProportion`)

| Field | Type | Notes |
|-------|------|-------|
| `type()` | `Type` | `SPLIT_EVENLY` (default) or `CUSTOM_PERCENTAGES` |
| `variants()` | `SortedSet<ExperimentVariant>` | `@Value.Default` → empty `TreeSet` |

`@Value.Check check()` enforces that every variant id resolves through `VariantAPI`, and that
weights sum to 100 when the set is non-empty. **Any rebuild of `variants()` must keep both
invariants**, or `build()` throws.

## ExperimentVariant (`AbstractExperimentVariant`)

| Field | JSON | Type | Notes |
|-------|------|------|-------|
| `id()` | `id` | `String` | control is `DEFAULT_VARIANT.name()` = `"DEFAULT"` |
| `description()` | **`name`** | `String` | control is `"Original"` (`ORIGINAL_VARIANT`) — note the JSON name differs from the accessor |
| `weight()` | `weight` | `float` | must sum to 100 across the set |
| `url()` | `url` | `Optional<String>` | **regenerated by FR-005** |
| `promoted()` | `promoted` | `boolean` | `@Value.Default` false |

`compareTo` sorts `DEFAULT` first unconditionally. A rebuilt set preserves that ordering for free;
appending to a `List` would not.

**URL format** (verbatim from `createExperimentVariant`, L1032):

```
page.getURI() + "?variantName=" + variantName
```

where `page` = `pageAssetAPI.fromContentlet(contentletAPI.findContentletByIdentifierAnyLanguage(experiment.pageId(), false))`.
FR-005 must reproduce this exactly, against the **new** `pageId`.

## ExperimentForm (`com.dotcms.rest.api.v1.experiments.ExperimentForm`)

Request body of the PATCH. Already carries the field — no change needed here.

| Field | Type | "absent" sentinel |
|-------|------|-------------------|
| `name`, `description` | `String` | `null` |
| **`pageId`** | `String` | `null` |
| `trafficAllocation` | `float` | `-1` |
| `lookbackWindow` | `int` | `-1` |
| `trafficProportion`, `scheduling`, `goals` | object | `null` |
| `targetingConditions` | `List<TargetingCondition>` | empty list (not null) |

`pageId` uses the `null` sentinel, so the guard is `experimentForm.getPageId() != null` — matching
the eight branches already in `patchExperiment`.

## DotExperimentPatchBody (frontend — PR #37064 branch only)

`core-web/libs/dotcms-models/src/lib/dot-experiments.model.ts` L40. Current shape:

```ts
export interface DotExperimentPatchBody {
    name?: string;
    description?: string;
    goals?: Goals;
    scheduling?: RangeOfDateAndTime | null;
    trafficAllocation?: number;
    trafficProportion?: TrafficProportion;
}
```

`pageId` and `targetingConditions` are deliberately absent, documented in the interface's doc
comment as "the page an experiment runs on is immutable once it exists". FR-013 relaxes `pageId`
only; `targetingConditions` stays out for its own unrelated reason (the backend would rebuild the
experiment's Rule from it). **The doc comment must be updated with the shape** — leaving it is
comment rot.
